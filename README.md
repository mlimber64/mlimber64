## 👨‍💻 Chi sono

Sviluppatore Full Stack con **oltre 5 anni di esperienza** nella progettazione, sviluppo e manutenzione di applicazioni enterprise. Sono specializzato in **architetture a microservizi** con **Java (Spring Boot, WebFlux)** e **.NET Core**, e in interfacce web con **Angular** e **Vue.js**.

Lavoro con team Agile (Scrum/Kanban) e ho a cuore la qualità del codice: test unitari, code review e quality gate con SonarQube.

## 🎯 Cosa so fare

- ⚙️ **Microservizi e API REST** con Java/Spring Boot e C#/.NET Core, seguendo SOLID e Clean Architecture
- ⚡ **Programmazione reattiva** con Spring WebFlux, Project Reactor e R2DBC
- 📨 **Messaggistica asincrona** tra servizi con Apache Kafka
- 🌐 **Frontend moderni** con Angular (fino alla v17) e Vue.js
- 🗄️ **Database relazionali e NoSQL**: PostgreSQL, SQL Server, MySQL, Oracle, MongoDB
- 🐳 **Docker e CI/CD** con Jenkins e Azure DevOps, monitoraggio con Grafana
- 📱 **App mobile** con Flutter nei miei progetti personali
